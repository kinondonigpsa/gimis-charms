An account is a person (GIMIS account, or phone / name when GIMIS account is not found). Blocking an account blocks all its computers, and any new computer registered under it starts blocked.

Updates for everyone

How it works: change the extension, raise version in manifest.json, reload it on THIS computer and test. Then press Publish. Every other computer notices within minutes and updates itself (one click to approve; a computer that has already allowed the folder updates by itself).
